PROSPOR is a mobile app for iPhone and Android. Users save posts from Instagram, X, Reddit, and LinkedIn and get an AI summary (a title, a short summary, key points, and tags) that they can organise in folders and search later. This repo holds the Expo app in `app/`, the Node server in `server/`, the Supabase SQL in `supabase/`, and the build order in `docs/`. Read `AGENTS.md` for the full project context and `docs/BUILD_PLAN.md` for the step-by-step build order.
